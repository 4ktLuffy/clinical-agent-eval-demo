# Findings

**The guardrail scored 82.7% recall on the turns it was written alongside and 8.1%
[5.8, 11.3] on held-out paraphrases it had never seen.** Labels unreviewed — the held-out
categories were assigned by the generating model, not a human, and this figure will be
restated with strike counts once that review lands. Both numbers are real and measured the
same way; the difference is provenance. The 180-turn subset was written in this repository
beside the keyword table that scores it, so its 82.7% is partly a memory test. The held-out
set is 382 positives and 405 in-scope negatives, 60+ per refusal category across four
registers, generated by a model used in no stage here, with zero overlap against the tuned
conversations and a test that keeps it that way. Precision fell the same way: 1.000 in-repo
against 0.674 [0.530, 0.791] held out. Mental-health recall was 1 of 69. Fifteen in-scope
negatives were refused outright — hospice parking, bringing a baby to an appointment, where
to store a bottle — because a keyword table matches a topic word and never reads the
request. Any in-repo evaluation number in this repository should be read as an upper bound.
That is the finding: not that this guardrail was weak, but that the harness reporting on it
could not see the weakness until the evaluation data came from somewhere else.

**Closing that gap took three attempts, and the first two are the instructive ones.** A
centroid stage over the original hashed bag-of-words vectors lifted held-out recall from
8.1% to 12.3% and cut precision from 0.674 to 0.452 — it fired on shared vocabulary rather
than shared meaning, so "we added a semantic stage" would have been true and would have made
the guardrail worse. Replacing the vectors with a pinned MiniLM sentence encoder took recall
to 31.9% [27.5, 36.8] at 0.689 precision, and adding exemplars drawn from policy text and a
retired development set took it to 51.0% [46.0, 56.0] at 0.886 [0.838, 0.922], with the
threshold re-derived each time by a rule fixed in advance against in-repo negatives only.
Chaining a small language model behind the centroid then reached 91.9% [84.9, 95.8] recall
on a seeded 200-line sample and dropped precision to 0.659 [0.577, 0.733]: it refused 46.5%
of in-scope callers, including 70% of the people asking an administrative question that
merely mentioned a symptom. Every one of those four configurations improves the headline
recall number, and two of them would make the system worse to be a patient of. The only
reason that is visible is that the negatives were built and measured alongside the
positives, on data nothing in the repository was allowed to tune against.
